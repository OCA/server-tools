To choose the format:

1. Go to *Settings > Phone Auto Format*.
2. Select the **Number format**: International, E.164, National, RFC 3966, or
   Disabled.
3. Select **Numbers per field**: allow several numbers in one field, or only
   one.
4. Click *Save*.

Numbers typed without a country prefix are parsed using the country of the
contact. If the contact has no country, the country of the current company
is used, so make sure each company has a country set.

The ``phonenumbers`` Python library must be installed on the server.
