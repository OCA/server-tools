To use this module:

1. Open or create a contact and set its country.
2. Type a phone number in any format, for example ``0300 1234567``, and leave
   the field. The number is rewritten in the configured format.
3. To store several numbers in a single field, separate them with a comma,
   for example ``0300 1234567, 0321 7654321``.

Existing records are not modified until they are saved again. To format
existing data in bulk, write the current phone values back to the records, for
example from an Odoo shell.
