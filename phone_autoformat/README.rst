This module formats phone numbers automatically when a contact is edited
or saved, so that every number in the database follows the same format.

- Numbers are reformatted as soon as the user leaves the field, and
  again on save (including imports and API calls).
- Every stored text field whose technical name contains ``phone`` or
  ``mobile`` is handled, including custom fields added with Studio.
- One field may hold several numbers, separated by a comma, a semicolon
  or a new line. Each number is formatted on its own.
- Numbers that cannot be parsed are left exactly as typed.

It relies on the ``phone_validation`` module and the ``phonenumbers``
Python library.

Configuration
=============

To choose the format:

1. Go to *Settings > Phone Auto Format*.
2. Select the **Number format**: International, E.164, National, RFC
   3966, or Disabled.
3. Select **Numbers per field**: allow several numbers in one field, or
   only one.
4. Click *Save*.

Numbers typed without a country prefix are parsed using the country of
the contact. If the contact has no country, the country of the current
company is used, so make sure each company has a country set.

The ``phonenumbers`` Python library must be installed on the server.

Usage
=====

To use this module:

1. Open or create a contact and set its country.
2. Type a phone number in any format, for example ``0300 1234567``, and
   leave the field. The number is rewritten in the configured format.
3. To store several numbers in a single field, separate them with a
   comma, for example ``0300 1234567, 0321 7654321``.

Existing records are not modified until they are saved again. To format
existing data in bulk, write the current phone values back to the
records, for example from an Odoo shell.

Known issues / Roadmap
======================

- Allow choosing the format per company.
