## Prerequisites

### System Requirements

- **Odoo 19.0** (Community or Enterprise)
- **Docker** and **Docker Compose** v2.x
- **docker-mailserver** (latest version recommended)
- Linux server with root access
- Valid domain with proper DNS records

### Required DNS Records

```dns
# MX Record (Mail Exchange)
@       IN  MX  10  mail.yourdomain.com.

# A Record for mail server
mail    IN  A   YOUR_SERVER_IP

# SPF Record (Sender Policy Framework)
@       IN  TXT "v=spf1 mx a:mail.yourdomain.com ~all"

# DKIM Record (generated by docker-mailserver)
mail._domainkey IN  TXT "v=DKIM1; k=rsa; p=YOUR_DKIM_PUBLIC_KEY"

# DMARC Record
_dmarc  IN  TXT "v=DMARC1; p=quarantine; rua=mailto:postmaster@yourdomain.com"

# Autodiscover (optional, for email clients)
autodiscover    IN  CNAME   mail.yourdomain.com.
autoconfig      IN  CNAME   mail.yourdomain.com.
```

## Docker-Mailserver Setup

### 1. Directory Structure

Create the following directory structure:

```bash
mkdir -p /opt/docker-mailserver/{config,data,state,logs}
mkdir -p /etc/odoo/mail_config
```

### 2. Docker Compose Configuration

Create `/opt/docker-mailserver/docker-compose.yml`:

```yaml
version: "3.8"

services:
  mailserver:
    image: docker.io/mailserver/docker-mailserver:latest
    container_name: mailserver
    hostname: mail
    domainname: yourdomain.com
    restart: always

    ports:
      - "25:25" # SMTP
      - "143:143" # IMAP
      - "465:465" # SMTPS
      - "587:587" # Submission
      - "993:993" # IMAPS

    volumes:
      # Mail data
      - ./data:/var/mail
      - ./state:/var/mail-state
      - ./logs:/var/log/mail

      # Configuration (shared with Odoo)
      - /etc/odoo/mail_config:/tmp/docker-mailserver

      # SSL certificates (Let's Encrypt)
      - /etc/letsencrypt:/etc/letsencrypt:ro

    environment:
      # Basic settings
      - OVERRIDE_HOSTNAME=mail.yourdomain.com
      - POSTMASTER_ADDRESS=postmaster@yourdomain.com

      # Security
      - ENABLE_FAIL2BAN=1
      - ENABLE_SPAMASSASSIN=1
      - ENABLE_CLAMAV=1
      - ENABLE_AMAVIS=1

      # Authentication
      - ENABLE_SASLAUTHD=0
      - ENABLE_LDAP=0

      # TLS/SSL
      - SSL_TYPE=letsencrypt
      - TLS_LEVEL=intermediate

      # Quotas
      - ENABLE_QUOTAS=1
      - POSTFIX_MESSAGE_SIZE_LIMIT=52428800 # 50MB

      # Logging
      - LOG_LEVEL=info

    cap_add:
      - NET_ADMIN
      - SYS_PTRACE

    healthcheck:
      test: ["CMD", "ss", "--listening", "--tcp", "|", "grep", "-P", "LISTEN.+:smtp"]
      timeout: 3s
      retries: 3

networks:
  default:
    name: mailserver-network
```

### 3. Environment Configuration

Create `/opt/docker-mailserver/mailserver.env`:

```bash
# Domain configuration
OVERRIDE_HOSTNAME=mail.yourdomain.com
POSTMASTER_ADDRESS=postmaster@yourdomain.com

# SSL/TLS
SSL_TYPE=letsencrypt
TLS_LEVEL=intermediate

# Security features
ENABLE_FAIL2BAN=1
ENABLE_SPAMASSASSIN=1
SPAMASSASSIN_SPAM_TO_INBOX=1
ENABLE_CLAMAV=1

# Quotas
ENABLE_QUOTAS=1

# Logging
LOG_LEVEL=info

# DKIM
ENABLE_DKIM=1
```

### 4. Start the Mail Server

```bash
cd /opt/docker-mailserver
docker compose up -d

# Check logs
docker compose logs -f mailserver
```

## Volume Configuration

### Shared Configuration Directory

The key integration point is the shared volume `/etc/odoo/mail_config` which maps to
`/tmp/docker-mailserver` in the container.

```
/etc/odoo/mail_config/
├── postfix-accounts.cf      # Email accounts (email|password_hash)
├── postfix-virtual.cf       # Email aliases/forwarding
├── dovecot-quotas.cf        # Per-user quotas
└── postfix-aliases.cf       # System aliases (optional)
```

### File Formats

#### postfix-accounts.cf

```
user@yourdomain.com|{SHA512-CRYPT}$6$salt$hash
admin@yourdomain.com|{SHA512-CRYPT}$6$salt$hash
```

#### postfix-virtual.cf

```
alias@yourdomain.com user@yourdomain.com
sales@yourdomain.com user1@yourdomain.com,user2@yourdomain.com
```

#### dovecot-quotas.cf

```
user@yourdomain.com:1073741824
admin@yourdomain.com:2147483648
```

## Permissions Setup

### Critical: File Permissions

The Odoo container must have write access to the configuration directory:

```bash
# Create odoo user/group if not exists
groupadd -g 1000 odoo 2>/dev/null || true
useradd -u 1000 -g 1000 odoo 2>/dev/null || true

# Set ownership
chown -R 1000:1000 /etc/odoo/mail_config

# Set permissions
chmod 750 /etc/odoo/mail_config
chmod 640 /etc/odoo/mail_config/*.cf 2>/dev/null || true

# Allow both containers to access
setfacl -R -m u:1000:rwx /etc/odoo/mail_config
setfacl -R -m u:5000:rx /etc/odoo/mail_config  # docker-mailserver user
```

### Docker Volume Permissions

In your Odoo docker-compose.yml:

```yaml
services:
  odoo:
    # ... other config ...
    volumes:
      - /etc/odoo/mail_config:/etc/odoo/mail_config
    user: "1000:1000" # Ensure matching UID/GID
```

### SELinux (if enabled)

```bash
# Allow container access
chcon -Rt svirt_sandbox_file_t /etc/odoo/mail_config
```

## Odoo Module Installation

### 1. Copy Module

```bash
cp -r mail_server_manager /path/to/odoo/addons/
```

### 2. Install Dependencies

The module depends on:

- `mail` (Odoo core)
- `base_setup` (Odoo core)
- `fetchmail` (Odoo core)

### 3. Install Module

```bash
# Via command line
odoo -d your_database -i mail_server_manager --stop-after-init

# Or via Odoo UI
# Apps → Search "Mail Server Manager" → Install
```

## Configuration Parameters

### System Parameters (ir.config_parameter)

Configure in **Settings → Technical → System Parameters** or via **Settings → General
Settings → Mail Server Manager**:

| Parameter                             | Description           | Example                         |
| ------------------------------------- | --------------------- | ------------------------------- |
| `mail_server_manager.mail_domain`     | Your email domain     | `yourdomain.com`                |
| `mail_server_manager.config_path`     | Path to config files  | `/etc/odoo/mail_config`         |
| `mail_server_manager.smtp_host`       | SMTP server hostname  | `mail` or `mail.yourdomain.com` |
| `mail_server_manager.imap_host`       | IMAP server hostname  | `mail` or `mail.yourdomain.com` |
| `mail_server_manager.imap_port`       | IMAP port             | `993`                           |
| `mail_server_manager.auto_create`     | Auto-create mailboxes | `True` or `False`               |
| `mail_server_manager.overwrite_email` | Overwrite user email  | `True` or `False`               |

### Example Configuration via XML

```xml
<record id="mail_domain" model="ir.config_parameter">
  <field name="key">mail_server_manager.mail_domain</field>
  <field name="value">yourdomain.com</field>
</record>
```

## Testing the Installation

### 1. Verify File Access

```bash
# From Odoo container
docker exec -it odoo-container bash
ls -la /etc/odoo/mail_config/
touch /etc/odoo/mail_config/test.txt && rm /etc/odoo/mail_config/test.txt
echo "Write access OK"
```

### 2. Create Test Account

1. Go to **Mail Server → Mail Accounts**
2. Click **Create**
3. Enter email: `test@yourdomain.com`
4. Save → Password wizard will appear
5. Copy the generated password

### 3. Test Email Sending

```bash
# From mail server container
docker exec -it mailserver bash
swaks --to external@example.com \
      --from test@yourdomain.com \
      --server localhost \
      --auth LOGIN \
      --auth-user test@yourdomain.com \
      --auth-password "generated_password"
```

### 4. Test IMAP Access

```bash
# Test IMAP connection
openssl s_client -connect mail.yourdomain.com:993
# Login: a LOGIN test@yourdomain.com password
# List: a LIST "" "*"
# Logout: a LOGOUT
```

### 5. Run Module Tests

```bash
docker compose run --rm odoo odoo \
    --test-tags mail_server_manager \
    -d your_database \
    --stop-after-init
```

## Troubleshooting

### Common Issues

#### 1. Permission Denied Writing Config Files

**Symptom:** `Permission error writing to the mail file`

**Solution:**

```bash
# Check ownership
ls -la /etc/odoo/mail_config/

# Fix permissions
chown -R 1000:1000 /etc/odoo/mail_config
chmod 750 /etc/odoo/mail_config
```

#### 2. SMTP Server Not Found

**Symptom:** `SMTP server not connecting`

**Solution:**

- Verify hostname in Odoo settings matches docker-mailserver
- Check network connectivity between containers
- Ensure port 587 is accessible

```bash
# Test from Odoo container
docker exec -it odoo-container bash
nc -zv mail 587
```

#### 3. Password Not Working

**Symptom:** `Authentication failed`

**Solution:**

- Reset password in Odoo
- Verify postfix-accounts.cf is updated
- Restart docker-mailserver to reload config

```bash
docker compose restart mailserver
```

#### 4. Emails Not Delivered

**Symptom:** Emails stuck in queue

**Solution:**

```bash
# Check mail queue
docker exec -it mailserver bash
postqueue -p

# Check logs
docker compose logs mailserver | grep -i error

# Flush queue
postqueue -f
```

#### 5. DKIM/SPF Failures

**Symptom:** Emails marked as spam

**Solution:**

- Verify DNS records are correct
- Check DKIM signing:

```bash
docker exec -it mailserver bash
cat /tmp/docker-mailserver/opendkim/keys/yourdomain.com/mail.txt
```

### Log Locations

| Component | Location                                             |
| --------- | ---------------------------------------------------- |
| Odoo      | `/var/log/odoo/odoo.log`                             |
| Postfix   | `docker logs mailserver` or `/var/log/mail/mail.log` |
| Dovecot   | `docker logs mailserver`                             |

### Debug Mode

Enable debug logging in Odoo:

```python
# In odoo.conf
log_level = debug
log_handler = odoo.addons.mail_server_manager:DEBUG
```

## Security Best Practices

1. **Use strong passwords** - Module generates 16-character passwords by default
2. **Enable TLS** - Always use encrypted connections (ports 993, 587)
3. **Regular backups** - Backup `/etc/odoo/mail_config/` regularly
4. **Monitor logs** - Set up log monitoring for failed auth attempts
5. **Update regularly** - Keep docker-mailserver and Odoo updated
6. **Firewall rules** - Only expose necessary ports
