⚙️ Configuration

Configure the module in Settings → General Settings → Mail Server Manager:

  • Mail Domain: Your email domain (e.g., company.com)
  • SMTP Host: Outgoing mail server address
  • IMAP Host: Incoming mail server address
  • Config Path: Path to docker-mailserver config files
  • Auto-create: Automatically create mailboxes for new users

🔧 Installation

# Copy module to addons folder cp -r mail_server_manager /path/to/odoo/addons/ # Update module list and install odoo -u mail_server_manager -d your_database
